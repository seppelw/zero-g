Zero-G Assistant

Schwerelose KI-Entwicklung & MCP-Orchestrierung mit Google Antigravity

Dienst wird initialisiert...

Warte auf Bereitstellung des Webinterfaces oder Erstanmeldung

1

Google Antigravity Authentifizierung

Antigravity benötigt eine einmalige Autorisierung mit deinem Google-Konto. Wähle eine der folgenden Optionen:

Option A: Über das Add-on Log

Öffne in Home Assistant den Reiter Protokoll (Log) dieses Add-ons. Dort findest du den personalisierten Google-Anmeldelink. Öffne ihn im Browser und bestätige die Berechtigung.

Option B: Token in Add-on Konfiguration

Hinterlege ein bestehendes OAuth-Token direkt in den Add-on Einstellungen unter auth_token und starte das Add-on neu.

2

Home Assistant MCP Server Integriert

Das Add-on konfiguriert den Home Assistant MCP Server automatisch über das interne Supervisor-Netzwerk:

MCP-Endpunkt: http://supervisor/core/api/mcp
Header: Authorization: Bearer <SUPERVISOR_TOKEN> (automatisch injiziert)

Dadurch kann Antigravity sofort auf Home Assistant Entitäten zugreifen, Automationen und Skripte generieren sowie Konfigurationen unter /config direkt bearbeiten.

⚡ Direkte Steuerung

Lichter, Schalter, Thermostate und Szenen über natürliche Sprache steuern.

📂 Konfigurationszugriff

Lese- und Schreibzugriff auf YAMLs, Blueprints und Lovelace-Dashboards.

3

Webinterface aufrufen

Die Antigravity-Laufzeitumgebung läuft nun erfolgreich im Hintergrund deines Home Assistant!

Um auf die KI-Entwicklungsumgebung zuzugreifen, nutze das offizielle Webinterface und verbinde dich über die Remote Control Funktion mit homeassistant-zero-g.
